# 词库详情收起标题与背景滚动隔离

用户要求移动词库详情沿用背词界面的单词收起行为，并反馈快速下滑偶尔露出底部导航。

- 新增详情外壳与独立顶栏，滚动内容单独在drawer-panel中。≤600px时，完整标题离开顶部后，在56px顶栏显示16px词头与关闭按钮；返回顶部恢复。沿用学习卡片的迟滞判断方向，避免临界点频繁切换。
- 关闭按钮在手机端定位于详情顶栏，保留32px可见圆形、44px命中区；桌面继续采用原先的固定位置，并明确层级避免被滚动面板覆盖。
- drawer-panel增加overscroll-behavior: contain；移动详情遮罩使用不透明主题背景，移除全屏backdrop-filter。
- 应用布局通过现存detail-overlay判断详情生命周期：打开期间main-area禁用背景滚动，bottom-nav隐藏且不可点击；关闭过渡结束、遮罩移除后恢复。无新增共享状态或全局监听。

排查确认：原版底部导航仅被遮罩覆盖，并未从背景隐藏；详情滚动边界未限制滚动传递。未在Chromium复现用户设备的瞬时闪烁，因此不能将这两点声称为实机故障的唯一原因。此次实现消除这两个条件，并减少移动端全屏滤镜合成。

验证：npm run check、生产构建；frontend-web/tests/libraryDetailScroll.browser.js覆盖320/390px、两套主题、顶部/中部/底部/返回顶部、快速大幅wheel滚动、背景位置保持、关闭后导航及滚动恢复、重开状态清理、桌面关闭按钮命中。截图在output/playwright/rich-responsive-references/detail-scroll-*。没有加入学习、删除、评分或其他业务写入。

结构复核：详情组件拥有收起标题和滚动容器，应用布局拥有背景滚动与底部导航显示；通过DOM生命周期联动，无新store或抽象。保持现状。路线图已检查，无优先级变化。

已重建前端容器供用户实测；移动Safari的惯性滚动、橡皮筋回弹、动态工具栏和实际闪烁是否消失仍需设备确认。
