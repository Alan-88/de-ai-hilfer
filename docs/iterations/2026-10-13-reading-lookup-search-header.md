# 文章快捷查词栏：词头与展开搜索统一顶栏

## 方向与实现

- PC快捷栏虽然位于宽屏，实际只有380px；与移动弹出栏共用主查词页的窄屏交互。常态展示居中26px词头、下方IPA和右侧搜索图标，不再常驻重复词头的输入框。
- 点击搜索图标后，胶囊输入从右侧横向展开并聚焦，词头暂时隐藏；保留词头原布局尺寸，开合不改变顶栏高度或解释滚动位置，长词仍原字号换行。减少动态效果模式禁用动画。
- PC常态不提供关闭常驻栏的箭头，展开搜索后显示收起箭头。移动常态左箭头关闭栏，搜索展开时先收起搜索。Escape、焦点离开整个顶栏或成功查询也收起；查询失败保留输入以便重试。焦点从输入移至箭头、提交或候选时不提前关闭。
- 候选保持独立圆角面板和滚动。根据visualViewport高度/偏移及栏底限制可见高度，软键盘缩小可见区域后重测；只对输入表单做展开裁切，避免裁掉候选。关闭时清空并失效化候选请求，迟到响应不能重新打开面板；组件生命周期内清理ResizeObserver及视口监听。
- 补查发现已有“手动查其他词后重新点击当前文章标记不刷新”问题：相同entry/key不会触发原选择effect。文章父组件每次selectWord递增selectionVersion，快捷栏响应这次选择并复用现有词条缓存；不把快捷栏手动查询反写为文章选中标记。
- 搜索/候选状态仍由ReadingLookupRail拥有，栏是否打开和文章选择由ReadingArticleView拥有。共享释义组件、API、CLI/MCP契约及文章正文排版不变，无新依赖。
