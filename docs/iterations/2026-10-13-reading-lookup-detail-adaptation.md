# 文章快捷查词栏同步详情排版

## 方向与实现

- 用户同意同步详情界面的字幕式中英释义与固定词头，并要求按 PC 快捷栏实际仍为窄栏的特点评估适配。
- ReadingLookupRail 开启已有 interleavedMeanings；词头与 IPA 音标移到滚动区之外，始终居中，26px 词头长词原字号换行。搜索头固定；移动关闭箭头放在左侧，44px 命中区，常态透明、hover/按下有背景、键盘焦点可见。
- 学习按钮留在正文滚动区右侧，32px高、11px文字、内容宽度胶囊且不换行；保留原学习状态及加入逻辑。
- 快捷栏成为名为 word-detail 的 CSS 容器，共享内容组件按其宽度适配。≤400px 释义中文14px/22px、英文11.5px/15px；≤340px 中文13px/20px、英文11px/14px。词性标签仍与首组双语居中，后续行使用完整宽度。
- 用法、德语例句及深度解析13px/1.5，例句中文11.5px/1.5；外层10px、条目6px、例句8px内距。保留条目与例句背景层级、字重、词汇网络直接展示。清除 ReadingLookupRail 对共享内容的旧全局样式覆盖。
- 原有共享组件的 viewport 规则继续服务词库、背词和查词。只有文章快捷栏声明该命名容器，不改变其他页面或文章正文/目录。未新增依赖、运行时宽度监听或业务状态。
