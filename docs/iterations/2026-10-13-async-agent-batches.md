# 通用异步批量入口与生成恢复

## 问题与结果

Spark每次写调用需审批，原MCP初始化虽然支持100个ID，却串行执行并等待整批返回，容易超时；文章仅单篇导入且无文件夹创建工具。用户明确要求通用操作清单，而非限定文章导入工作流。

实现受保护Agent API的提交/列表/详情/重试；后端持久保存不可变请求与步骤结果，最多3批同时执行，批内操作有序。支持初始化、学习归属add/remove/reset、文件夹创建、文章导入，任意组合。ID可引用前序结果；显式依赖要求整步成功，部分初始化成功项仍可引用。默认失败继续，stop跳过后续，不回滚已成功内容。

同key同请求复用任务，不同内容拒绝。目录/文章创建、学习变更与操作凭据同事务提交，恢复不会重复创建或再次reset。任务锁跨进程防重复执行，启动自动恢复queued/running；逐词处理中/成功/失败结果持久化。

## 生成链路

- Web同步/流式与Agent共用单进程3路生成限额；同原型锁覆盖知识缓存复查到落库，重复请求复用词条。
- A、B、完整C通过现有验证后分别保存，24小时有效；B失败复用A，C失败复用A+B，C完成但落库失败仍可复用C。key包含词典实际事实与合并数据、实际prompt、质量、模型与路由；强制重新生成绕过缓存。A网络临时故障有限重试，B/C已有重试与质量闸门保留。
- 原30分钟进程内AB缓存改为数据库阶段缓存，既有离线AB结构保留；不增加Redis或依赖。
- 运行任务/凭据不属于用户内容备份；全量恢复拒绝未完成任务，成功恢复清除旧运行数据，防止旧ID复用。既有内容备份格式不变。

## 客户端与维护

- MCP 0.3新增batch_submit、batch_query、batch_retry；lexeme_initialize参数兼容并加可选key，但响应有意改成异步任务，指南明确必须轮询后判断完成。
- CLI新增batch submit/get/list/retry、initialize --async/--idempotency-key，原同步默认保留；便携CLI同步，仓库/便携Skill、MCP初始化说明和按需batch_operations指南同步。
- 完整schema、样例、状态、重试与恢复边界见 `docs/api/agent-batches.md`。
- 同步检查current-state、active-roadmap和iterations，撤销路线图旧的“后台批量生成队列不排期”表述。

## 验证

- Rust46项单元测试通过，`cargo check --all-targets`通过（已有dead_code与sqlx future-incompat提示保留）；隔离PostgreSQL+模拟AI阶段集成测试显式运行通过。普通测试默认跳过该集成项，避免误用真实数据库。
- MCP构建及8项测试通过，覆盖OAuth保护、发现11个工具、混合操作schema、异步初始化只发一个提交请求、只读查询与同任务重试；CLI转发测试及仓库/便携自检通过。
- 独立测试后端进程验证：未认证401、无效依赖400、立即返回202/queued，终止时数据库仍为queued；新进程启动自动执行完成，同key复用任务、改内容409。没有写生产文章或学习数据。
- 隔离测试覆盖顺序与引用、部分成功与依赖跳过、stop、key冲突、成功项不重跑、写成功后丢失步骤结果的恢复、reset不重复执行、同词并发落一条、A/B/C恢复、完整C同步/流式复用、强制刷新绕过及备份恢复互斥。
- architecture-review结论：结构合理，保持现状。任务编排调用既有业务服务，事务校验与操作凭据在业务所有者内，数据库访问留在repositories；MCP不拥有执行队列，CLI/Skill与指南只消费契约。未增加全局前端状态或新依赖。
- Docker后端Rust1.88生产构建与MCP Node22构建成功；已仅重建部署backend/mcp-gateway，新增迁移完成。公网status/db_status均ok，CLI批量列表读取成功；真实OAuth+PKCE、11工具发现、batch_query只读读取与batch_operations指南通过，网关healthy。未提交生产任务或触发真实模型计费；隔离测试容器与测试卷已清理。

## 边界

没有代替Spark审批策略；没有任意HTTP/代码执行、日内纠正批量化或多副本统一生成配额。阶段缓存24小时有效，真实模型配额下的并发体验仍需使用观察。未改前端。后端部署重启会使现有内存学习session失效，重新进入学习页会按持久日志恢复。
