# 词库详情固定词头与边缘返回

用户确认居中固定词头方案，并要求移动端仅在边缘附近右划关闭。本轮只改词库详情，不调整其他详情页、字幕式释义、正文密度或业务接口。

## 行为

- 单一h2词头从打开起相对详情抽屉居中固定，取消原本双标题、滚动阈值、缩小和切换逻辑。桌面40px，601–768px为32px，≤600px为26px，保留各断点原始词头字号。
- 顶栏与正文采用两行grid，正文独立滚动。通常顶栏72px/56px，长词原字号自然换行，顶栏高度由当前词确定，滚动时不变化。左右对称留出返回按钮安全区。
- 左上箭头“返回词库”仍调用原关闭回调，不执行浏览器历史后退。常态透明、无描边和阴影，44×44px命中范围；鼠标hover和按下显示圆背景，键盘focus-visible有主题色描边。触屏不使用滞留hover。
- 元数据与学习动作移到词头下方同一行，允许元数据换行。已有底部胶囊按钮与桌面16px底部固定留白保留。
- ≤600px仅接受单指从详情左侧0–20px起手的右划，结束时横向位移≥72px且大于纵向位移的1.5倍才关闭。明显纵向或反向移动、多指、touchcancel放弃本次手势；确认水平移动前不阻止原生滚动。
- 手势监听由详情组件本地action安装、卸载，无全局监听或共享状态。关闭或更换词条同步清理语法弹窗。PC空白区域点击关闭及原背景滚动/底部导航隔离保持有效。
