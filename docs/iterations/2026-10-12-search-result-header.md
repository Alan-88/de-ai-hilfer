# 查词结果居中词头与按需搜索

## 用户方向

- 结果页参考词库详情，把单词固定到顶部居中，音标在下方，返回箭头在左侧，搜索入口在右侧。
- 窄屏先横向展开搜索，词头暂时收起；宽屏保留可直接输入的短搜索栏，宽度随可用空间调整。宽屏不展开的比例先试用，待实际截图与体验后再定。
- 保留现有正文密度、主题、胶囊外形和联想功能，不扩大到其他页面。

## 实现

- SearchPageView统一解析结果，并将同一份structured传给SearchResultCards，确保顶部展示的解析词头/音标与正文一致，不重复解析。正文移除重复词头与音标，释义、元数据及操作保留。
- 顶栏使用左右等宽的三列，词头不随滚动位移或缩小；长词按原字号换行。音标继续使用兼容IPA的字体栈。
- PC顶栏使用整个主区域宽度，不受正文960px上限约束，避免大屏搜索栏变宽却挤压词头；正文原最大宽度和边距保留。
- ≤1200px右侧为44px搜索图标，展开/收起使用260ms横向揭示动画；减少动态效果时跳过运动。左箭头在聚焦时先收起搜索，否则返回首页；边缘右划使用同一处理。
- >1200px保留短搜索栏，宽度按扣除侧边导航和正文边距后的可用空间30%计算，限制240–340px。相同宽度预留在左侧，保证词头居中。聚焦不改变外栏宽度，联想/候选可以使用最多420px的下方面板。
- 窄屏生成期间右侧入口显示停止图标，可直接取消；宽屏保留搜索栏内的取消按钮，避免搜索默认收起后失去取消入口。顶栏返回/搜索图标采用与词库一致的24px、44px命中区。
- 取消回归发现原按钮在取消时立即从button变为submit，浏览器随后执行默认点击动作又提交了一次（实测POST从1变2）。取消分支显式preventDefault，避免重新请求。
- 展开搜索与取消保留结果及阅读位置；输入、联想切换、候选选择、搜索提交、加载取消、错误恢复继续使用原业务逻辑。首页上移/归位动画保留。
- 实测发现PC原右上主题开关遮挡新搜索入口；仅查词结果页将该开关放到侧栏下方，其他页面和移动端主题入口保持原逻辑。

## 范围

- 仅Web组件改动，无API/CLI/Skill/MCP契约变化；检查active-roadmap，无优先级变化。
- 只重建frontend容器，不重启backend与MCP，保留学习会话。
- 真实浏览器截图使用只读GET取得已有abnehmen词条，并在浏览器中复用该响应，避免生成新分析或写入业务数据。
- 改前截图为output/playwright/search-result-before-*；改后/搜索展开/滚动状态为search-result-after-*、search-result-search-*、search-result-scrolled-*。检查脚本为search-result-header-check.js。
