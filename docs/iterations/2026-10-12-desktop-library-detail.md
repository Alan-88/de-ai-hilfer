# 词库详情桌面适配

用户授权将手机探索出的信息组织、标签协调和滚动定位迁移到PC，试点仅限词库单词详情。

## 行为与出发点

- 字幕式B排版扩展到桌面核心释义，中英文仍各自自然折行后按视觉行交错，不表示逐行翻译对应。英文或中文更长时完整保留尾行。
- 桌面中文16px/24px、英文13px/18px，行组间4px；英文从原先继承small得到的约11.1px改为明确13px。桌面阅读层级单独校准，不复制手机密度。
- 桌面词性标签12px字、24px高，与首组中英行居中；第一行避让标签，续行利用完整宽度。保留桌面hover/focus语法提示与点击弹窗。
- ≤600px仍是中文13px/20px、英文11px/14px、词性11px/20px、行组间3px；移动释义内边距维持10px，不受桌面信息图标预留空间影响。
- 桌面滚动后在72px顶栏显示18px词头，相对800px详情抽屉居中，关闭按钮与其固定；返回顶部恢复大标题。长词可换行，收起后省略并给关闭按钮保留空间。
- 桌面滚动容器底部增加固定16px主题色留白，正文不再直接贴到视口底边；不改变底部操作按钮的布局。手机仍沿用原来的56px顶栏和底部处理。
- 普通查词、背词和文章查词栏未启用此排版。LearningAnalysisContent原compactMeanings参数改为interleavedMeanings（默认关闭），词库详情仍是唯一启用者；移除仅为手机分支存在的matchMedia监听。
