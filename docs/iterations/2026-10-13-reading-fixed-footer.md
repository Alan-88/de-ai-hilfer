# 文章标题栏收口与固定窄底栏

## 实现

- 用户要求Wörter与标记数固定到底栏，以右下角标记数按钮替代顶部“标记词”入口，缩小按钮，释放标题空间。
- ReadingArticleView的article-pane保留上下栏，中间新增article-scroll独立滚动；顶部不再依赖sticky，底栏不再作为正文末尾内容。短文章仍保留原上下留白与正文视觉居中，长文章能滚到底。
- 顶部仅展示文章标题与返回/编辑入口，移除目录路径及重复的顶部操作；标题原字号保留，长标题省略并可通过title读取全文。顶栏PC最小66px、≤600px最小56px。
- 底栏44px高、左右12px内距，左侧Wörter、右侧32px胶囊“数量 标记”。复用原标记菜单状态/事件及跳转/取消标记逻辑，空标记按钮禁用。移动快捷查词图标同步移到底栏、保持原打开逻辑。
- 标记列表从底栏上方向上展开，以文章面板定位，宽度不超出面板，最大高度受文章面板约束，长列表独立滚动。点击栏外继续关闭，点击条目仍跳到原文并加载右侧词条。
- 改动仅在文章组件本地样式/布局；正文文字、标记锚点及选择流程、编辑、快捷查词、API/CLI/MCP契约保留。无新依赖或全局状态。
