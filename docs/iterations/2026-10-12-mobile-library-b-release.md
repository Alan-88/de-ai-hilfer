# 词库详情移动密度 B 版上线

用户结束按义项配对的A线，选择继续探索按视觉行交错的B线，随后明确要求部署供实机测试。本轮将浏览器样稿接入正式组件。

## 当前行为

- 仅词库详情、≤600px启用；中文13px/20px，英文11px/14px，行组间3px。中英文独立自然折行，再交错展示，视觉相邻不表示逐行语义对应。
- 词性标签20px高、文字11px，相对首组双语行居中；第一行缩进，续行回到标签左边缘。无英文时标签与中文行对齐；英文多出的行继续显示，不截断。
- 长解释与德语例句13px、行高1.5，例句中文11.5px；标题26px，外层卡片/说明/例句内边距10/6/8px，保留背景、字重、强调线和44px关闭按钮。
- 10.5px英文试验未带来额外行数收益，正式版保持11px。桌面、学习页和文章查词栏保持原排版。

## 实现与验证

- InterleavedMeaning拥有测量、断行和清理生命周期；ResizeObserver在宽度变化时重新计算，字体加载完成后重排。逐字Range测量沿用浏览器实际断行，超长连续文本允许折行；屏幕阅读器仍读取完整中文、完整英文，不读取重复的测量文本。
- LearningAnalysisContent通过默认关闭的compactMeanings参数接入，词库详情是唯一启用者。组件卸载清理观察器、字体监听和动画帧；旧英文占位样式移除。
- npm run check与生产构建通过，类型检查仅保留两项既有warning。
- 浏览器回归脚本：frontend-web/tests/interleavedMeanings.browser.js。覆盖两套主题、320/390/600/601/1280px及返回手机尺寸、逐语言全文保留、无二次折行或横向溢出、标签居中、语法弹窗可打开。只在浏览器替换GET响应验证英文1对4行、缺少英文；没有写业务数据。
- 真实abnehmen：390px首屏3条完整例句，320px2条。截图为本机output/playwright/rich-responsive-references/b-live-{320,390,1280}-{canvas,canvas-dark}.png。
- 仅重建前端容器，公开页面已核验。路线图已检查，无优先级变更。

结构复核结论：保持现状。新组件负责独立的布局测量生命周期，页面负责启用范围与整体密度，没有引入业务状态或后端接口。

待用户验证实体手机长时间阅读、系统文字放大、移动Safari字体与动态工具栏表现；本轮浏览器检查使用Chromium。
